## 0. 前代与废除名单

本版取代以下设计。**废除理由全部记录在案**，后人（包括AI）不得复活它们，除非理由被推翻。

| 被废除 | 死因 |
|---|---|
| 12兵种体系 | 过度设计，超出"最小自洽循环"，理解成本爆炸 |
| 矿车 | 违反宪法第1条：果实有时直飞、有时要运，世界规则随车辆组合变化 |
| 偷窃车 | 车辆消减由战斗车炮弹统一承担，独立的"偷"动词冗余 |
| 城管车（威慑/扣押） | 同上。威慑无法一句话讲清，"炮打一切实体"一句话讲清 |
| 撞车互毁规则 | 被炮弹规则吸收。车辆间唯一交互=炮击 |
| 孤魂野鬼树 | 无偷窃车后自然死亡 |
| 圈地升级 / 一切升级体系 | 违反宪法第2条：能力全固化 |
| DeepSeek版"毁巢获胜/3分钟/能量滚雪球" | workbuddy版已纠正为2分钟/纯占地%/能量仅时间回复 |

**保留并确认**：广度优先铺地（≥2邻接己方格选点）、方块可拆（领土可逆）、影子对战=镜像模式、果实直飞基地。

## 1. 设计宪法（三条最高原则，任何新设计不得违反）

1. **世界规则一致性**：规则不随车辆组合变化。果实永远直飞回家；炮永远能打一切敌方实体；任何新单位只是新皮肤+新数值，不引入新规则。
2. **能力全固化**：无升级、无等级、无成长。力量=数量。平衡只调经济和产量。
3. **最小自洽循环+减法测试**：任意一辆车删掉，核心循环必须还能转；删掉后游戏只是"变单薄"而非"出故障"。

---

## 2. 核心循环

```
铺地（扩张） → 种树（经济） → 果实直飞（+⚡） → 生产更多车
     ↑                                              ↓
     └──────────── 战线推进：铺到对方工厂底下，炮轰掉它
```

一句话：**这是一个"用砖头把战线顶过去"的游戏。** 铺地车是战斗车的射程延伸——每铺一块砖，就是未来的一座炮位。

## 3. 规则书（全游戏12条，就这么多）

**世界**
1. 地图 18×30 格（沿用 canonical ✅），双方工厂各在己方最后方。工厂是唯一生产点，也是被守护者。
2. 货币 ⚡，**无上限**（workbuddy 版 cap 8 作废——攒能爆发设计需要银行）。初始 10⚡（=5辆铺地车 ⚠️）。

**三辆车**
3. **铺地车** 2⚡：载5砖，广度优先选点（目标格≥2邻接己方格，平手取离工厂最近；无候选时退化为≥1邻接），每格铺设0.5秒，空载回厂补货。
4. **种树车** 3⚡：载3树（头顶3格小方格实时显示库存，铺地车同理显示5砖），只在己方格种植，每棵停留3秒。选点=势场最洼（§4.2）。
5. **树**：每6秒结1果，果实直飞工厂+1⚡。树阻挡车辆通行，HP 30⚠️。树只能种在己方格上。
6. **战斗车** 20⚡：只能在己方格上移动/驻停，最远到己方边界格。**目标优先级：车 > 砖 > 树**（同级取最近）。射程6格，射速1炮/1.5秒。
7. 炮弹伤害一切敌方实体。砖HP 50⚠️ / 强化砖HP 150⚠️。车辆HP：铺地车20 / 种树车20 / 战斗车100⚠️。
8. **撤退规则**：战斗车所站格被拆→强制花1秒撤到最近己方格，期间不开炮，然后重新索敌。

**生产**
9. 点击=入队一辆，建造2秒，队列**并行**（连点4下=4辆同时建造），出厂间隔0.3秒防叠车。
10. 无升级：所有能力永远固化（宪法第2条）。

**胜负**
11. **状态胜利制，默认无时限**（v2.1 修订：废除2分钟计时器——压力只来自AI，不来自钟）。默认条件V1：己方领土≥85%即胜。计时器仅在V6生存局以"波次"形式存在。完整变体见§13。
12. 影子对战（镜像模式）：影子复刻玩家每一次出兵——同费、同量、镜像位置。地图非完全对称（水洼等不可铺障碍）制造选点分歧，蝴蝶效应放大。

**世界定律（v2.1 增补）**
13. **归属律**：一切植被层实体的归属 = 其脚下砖块的归属。砖没了实体不消失（孤魂野鬼），呈"待认领"态，谁先铺上自己的砖，实体归谁操作。
14. **装载律**：战斗车有1个货舱（旗/公主）。车辆被击毁→货物掉落在该格地面，**影响存留不重置**；任何一方战斗车停在货物邻格且脚下为己方砖时可装载。

## 4. 三车详细设计

### 4.1 铺地车 Worker（"快递员"）

**FSM**：
```
LOAD(5砖,1s) → SELECT_TARGET → MOVE → PLACE(0.5s/格)
   ↑                                        │
   └──────── RETURN(空载) ←── 库存=0 ───────┘
任意态: UNDER_FIRE → FLEE(向工厂逃跑) → LOAD
```

- 可行走格：己方格 + 中立格。**不可进入敌方格**。
- 遇炮击不反击，逃跑。视觉上就是小车被追得满街跑——这是设计，不是缺陷。

### 4.2 种树车 Planter（"园艺拖拉机"）

FSM 与铺地车同构（LOAD→SELECT→MOVE→PLANT→RETURN），唯一差异在 SELECT：

**势场选点算法** 🔍：
```
potential(c) = Σ_树 max(0, 10 − manhattan(c, 树))   # 每树：本格10，外圈9、8…7，>10无影响
候选 = 己方格中 potential 最低的第3~5名
目标 = 候选中离工厂最近的
每次种完一棵重新计算
```

效果：树自动离散分布、不扎堆、离果园越远越敢种（那里势场最洼）。小地图上呈"田园牧歌"散布美学。扎堆的替代方案被否决：单一果园=单一风险点，被炮轰时经济全灭。

### 4.3 战斗车 Fighter（"清道夫"）

**FSM**：
```
SPAWN → ADVANCE(向己方最前推进, 直到射程可覆盖敌方实体)
      → ACQUIRE(射程6内: 车>砖>树, 同级最近)
      → FIRE(1.5s冷却) → 循环
异常: 站格被拆 → RETREAT(1s, 禁止开炮) → ADVANCE
移动约束: 目标格必须为己方格, 否则拒绝移动
```

- **领土锁定是本设计的神来之笔**：战斗车锁己方→国界自然形成→双方战斗车在边界内对峙开炮→谁铺得快谁把战线顶过去。侵略不靠越境，靠砖头。
- 禁止 rush：开战时不可能直接威胁对方工厂，工厂在最后的最后方。
- 没有战斗车的区域=不设防。果园要不要留守卫，是玩家的资源分配题。

**炮拆砖速度 vs 铺地车铺砖速度**。炮快→防线永远守得住→僵局；铺快→战线必然碾压→竞速无对抗。两者比值=对抗强度旋钮。初值状态下：1炮7.5秒拆1砖（50HP÷10×1.5s），1铺地车0.5秒铺1砖——10:1，显然失衡，意味着**防御天然劣势，进攻靠数量堆**。这是刻意的：它制造"必须攒能爆发"的需求，与第9条并行生产闭环。

## 6. 对抗结构分析

### 6.1 三层消减（取代被废除的偷窃/城管体系）

| 层 | 对象 | 机制 |
|---|---|---|
| 对地 | 砖、树 | 炮轰 |
| 对车 | 三车皆可 | 炮轰 |
| 对经济 | 果园、铺地线 | 炮轰 |

一种伤害类型全覆盖（宪法第1条）。车辆消失=被炮打死，干净。

### 6.2 战线动力学 🔍

国界不是线，是"双方炮口重叠的地带"：
- 我方铺地车前推1格 → 我方战斗车可驻停格+1 → 射程压向对方砖 → 对方站格被拆 → 对方撤退 → 我方铺地车覆盖其砖 → 战线推进。
- 逆向同理。战线是活的，随铺地速度和炮的存量来回摆。

### 6.3 经济赌博 🔍

攒能200⚡期间战斗车为零——对方此刻推线，果园就是活靶。所以爆发前必须在国界留对峙兵力。**攒能=走钢丝**，这是本游戏的核心心理张力，也是操作深度所在（什么时候攒钱、什么时候爆发）。

### 6.4 节奏（v2.1修订）

无时限状态制下，节奏由AI压力驱动而非时钟：开局0~60s仍是抢中立窗口（实测中位61.0s中立清零✅，若对手是田园派则经济竞速，军工派则全程施压）。对局长度=到达胜利状态的自然时长，预估3~8分钟⚠️。

## 7. 影子对战（镜像模式）规则

1. 影子复刻玩家每一次出兵：同费、同量、镜像位置（棋盘翻转）。

3. 影子不读未来信息，同一时间获知与玩家相同。
4. ~~镜像是否复制卡牌等级~~ —— **此问题随升级体系废除而自然死亡**（宪法第2条）。镜像永远同级，因为根本没有级。

# 扩展章 v2.1 · 关卡系统与留存

## 12. 两层世界模型（v2.1 架构增补）

整个世界是两层结构，一切地图特殊物都是同一数据结构的皮肤：

| 层 | 内容 | 规则 |
|---|---|---|
| **砖层（地基）** | 普通砖50HP / 强化砖150HP | 谁铺归谁；可被炮拆 |
| **植被层（地上物）** | 树（30HP）/ 任务建筑（超HP树）/ 旗 / 公主 | 归属=脚下砖归属（归属律）；挡车辆通行；可被炮打；砖没了不消失 |

**归属律**是孤魂野鬼树的宪法化复活：当年废除的是"偷窃车"，不是"归属跟随地面"的思想。一棵树、一面旗、一位公主，谁的地盘就归谁操作——一条定律全覆盖。

## 13. 胜利条件变体 V1~V7

默认V1，其余为地图配置。计时器默认废除（V6除外）。

| # | 名称 | 判定 | 气质 |
|---|---|---|---|
| V1 | 占比胜利 | 己方领土≥85% | 默认轻松局 |
| V2 | 工厂摧毁 | 敌方工厂HP归零 | 终局型，最漫长 |
| V3 | 拆建筑 | 敌方N座任务建筑全灭 | 逼你铺路进腹地 |
| V4 | 夺旗 | 战斗车把旗运回己方工厂，累计N次 | 拉锯热点 |
| V5 | 救援 | 战斗车装公主→爬回己方工厂 | 与V4同构 |
| V6 | 生存 | 撑过军工派X波猛攻 | 唯一用计时器的变体 |
| V7 | 丰收 | 无AI，限时收N颗果实 | 禅模式，规划型玩家入口 |

### V4/V5 装载细则（装载律）

1. 装载前提：货物脚下是**己方砖**（旗点初始在敌方腹地，须先铺到旗下）。
2. 装载动作：战斗车停在货物邻格，自动装载（1秒），货舱=1。
3. **掉落存留**：载货战斗车被击毁→货物掉在该格。**不重置**。掉在敌方砖上=敌人可装载（旗可被运回原点=防守成功一次；公主入敌方工厂=任务失败⚠️）；掉在无砖中立格=待认领，**谁先铺砖归谁**——掉落瞬间变成抢地竞赛。
4. 成功送达：旗+1分、旗归位；公主送达=直接胜利。
5. 装载不影响力：战斗车载货期间正常开炮（能力固化，货舱只是上下文）。

## 14. 后进者优势——增益球系统

**触发**：领土差≥15% 或 能量差≥30⚡ → 战线中点±3格处，每20秒掉落一个增益球，同场至多2个。

| 球 | 效果 | 外观 |
|---|---|---|
| 🟡能量球 | +15⚡，直飞回家（果实直飞律延伸） | 金球内闪电 |
| 🔵护盾球 | 拾取车辆5秒无敌金盾 | 蓝球内小盾 |

**设计原则**：球掉在**双方都能抢的位置**，不是落后者后院。本质是"在败局里制造新目标"——领先者不来抢就是放血。纯施舍会侮辱玩家，可争夺的翻盘机会不会。

## 15. AI性格与难度刻度

AI决策=每N秒将能量按概率分配给三车。性格=三个旋钮，难度=决策间隔，全部零作弊（不偷看、不加数值）。

| 性格 | 铺/种/打 投资比 | 手感 |
|---|---|---|
| 田园派（经济狂） | 高铺高种，憋能阈值极高 | 前期人畜无害，后期车队如潮 |
| 军工派（憋炮狂） | 约六成砸战斗车，低阈值频繁爆发 | 全程压迫感 |
| 镜像派 | 复刻玩家（影子） | 战胜另一个自己 |

难度刻度：懵懂10s / 入门6s / 标准4s / 高手3s 决策间隔。
