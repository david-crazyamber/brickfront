## 三车

| 车 | 职责 | 一句话 |
|---|---|---|
| 铺地车 | 扩张 | 铺一块地，让世界变大（战斗车的射程延伸） |
| 种树车 | 经济 | 种树，绿球直飞回家变⚡ |
| 战斗车 | 清道夫 | 炮轰射程内一切敌方实体（车>砖>树） |

## 世界定律

- **归属律**：植被层实体（树/建筑/旗/公主）归属 = 脚下砖归属。砖没了不消失，先铺先得。
- **装载律**：战斗车1货舱；被击毁货物掉落存留不重置。

## 设计宪法

1. 世界规则不随车辆组合变化
2. 能力全固化，力量=数量，无升级
3. 最小自洽循环+减法测试
